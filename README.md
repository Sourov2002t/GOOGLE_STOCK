# Google Stock Analysis & Forecasting (2010–2023)
## Overview

This project analyzes Google (GOOGL) stock data from 2010 to 2023 using SQL, Python, machine learning, and deep learning techniques.
The focus is on understanding long-term trends, market behavior, and short-term price forecasting rather than pure prediction.

## Dataset

Daily stock data (Open, High, Low, Close, Volume)

Period: 2010–2023

Total records: 3,415 trading days 

Google Stock Analysis_SQL

## Tools & Technologies

Python: pandas, numpy, matplotlib, seaborn

SQL: MySQL (advanced analytical queries)

ML: Scikit-learn (Random Forest)

Time Series: ARIMA (statsmodels)

Deep Learning: TensorFlow/Keras (RNN, LSTM, GRU)

## Key Work Done

Data cleaning, feature engineering, and time-series indexing

SQL-based analysis of price trends, volume, returns, and volatility

Next-day price direction prediction using Random Forest

Price forecasting using ARIMA

Deep learning models (RNN, LSTM, GRU) with sliding window sequences

Model evaluation using RMSE, MAE, R², and visual comparisons

## Key Insights

Google stock shows strong long-term growth with short-term volatility

Daily gains and losses are nearly balanced, reflecting market efficiency

LSTM-based models performed best for price forecasting

Ensemble predictions improved stability over single models
